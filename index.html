PROJECT 01 / AGENT

数学建模全栈辅助 Agent

一个面向数学建模全流程的阶段化智能协作系统。

问题

资料检索、分析、写作、绘图和排版工具分散，经验难沉淀，流程难复用。

方案

以阶段识别为入口，编排 5 类 Skill；搭建本地 RAG 与知识图谱；设计 15 套 Prompt 与统一 JSON 输出契约。

验证

构建 8 条固定标注任务离线评估集，经 5 轮迭代，阶段识别准确率从 62% 提升至 87.5%。

结果

工具路由召回率和 RAG TopK@3 命中率均达到 100%，形成可复用工具链。
